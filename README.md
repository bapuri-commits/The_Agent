## Core Principles
- **SSOT**: 구조화된 DB가 유일한 진실의 원천
- **Deterministic Planning**: 같은 입력 → 같은 결과
- **LLM 역할 제한**: 구조화/분해/설명만, 의사결정은 코드
- **Execution > Advice**: 조언이 아닌 실행 중심
- **Failure-safe**: 모델이 틀려도 시스템은 무너지지 않음

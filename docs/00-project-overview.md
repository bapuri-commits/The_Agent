# 00 — Project Overview

## 프로젝트명
**The Agent** — Personal AI Secretary (ADHD-friendly, Performance-first)

## 한 줄 요약
ADHD 환경에서 학교 + 일상 전반을 커버하는 **고성능, 고신뢰, 실행 중심** AI 비서 시스템.

---

## 왜 만드는가

- 컴공 학생 + ADHD → 일정/할 일 관리가 구조적으로 어려움
- 기존 할 일 앱(Todoist, Notion 등)은 "기록"은 되지만 "실행"까지 이어지지 않음
- AI 챗봇의 "조언"은 참고만 하고 끝남 → 행동 변화 없음
- 필요한 것: **입력은 5초, 계획은 자동, 실행은 강제** 되는 시스템

---

## 핵심 원칙 (6가지)

### 1. SSOT (Single Source of Truth)
- 대화 로그가 아니라 **구조화된 데이터베이스**가 유일한 진실의 원천
- 모델이 추측하지 않음, 계획이 흔들리지 않음, 장기 기억이 유지됨

### 2. Deterministic Planning (결정론적 계획)
- 같은 입력 → 같은 출력
- 우선순위 점수는 명시적 수식으로 계산, LLM이 결정하지 않음
- 감정/문장 톤에 따라 결과가 바뀌면 안 됨

### 3. LLM 역할 제한
- LLM은 **보조자**: 텍스트 구조화, 작업 분해, 인간 친화적 설명
- LLM은 **의사결정자가 아님**: 우선순위, 일정 배치, 규칙 적용은 코드가 담당
- 이유: 재현성, 비용 통제, 환각 방지

### 4. Execution > Advice (실행 > 조언)
- "하면 좋겠다"가 아니라 "지금 이것을 해라"
- 계획은 매일 흔들리면 안 되고, 미이행 시 자동 재분해/재계획
- Enforcement 3단계: Narrowing → Commitment → Escalation

### 5. Capture Friction ≈ 0 (입력 마찰 제로)
- 입력은 5초 안에 끝나야 함 (1줄 텍스트 중심)
- 부족한 정보는 기본값 자동 채움 (est=60min, importance=3)
- 데이터 입력량 = 시스템 성능 → 입력이 쉬워야 데이터가 모임

### 6. Failure-safe (실패 안전)
- 모델이 틀려도 시스템은 무너지지 않음
- Fallback 모드: Minimal Plan / Urgent Only / Recovery
- 불변 규칙: 마감 24h 이내 = 항상 최상단, 수면 시간 이후 일정 금지

## 성능 정의

"성능"은 모델 지능이 아니라 다음 6가지의 합이다:

| # | 성능 지표 | 의미 | 측정 방법 (v2+) |
|---|----------|------|----------------|
| 1 | 실행 성공률 | 사용자가 실제로 행동했는가 | task 완료율 |
| 2 | 일정 안정성 | 같은 조건에서 계획이 흔들리지 않는가 | 동일 입력 재실행 diff |
| 3 | 지연 최소화 | 입력~응답 시간 | API latency p95 |
| 4 | 재현 가능성 | 결정론적 출력 | 단위 테스트 |
| 5 | 컨텍스트 유지 | 장기 기억 정확도 | 과거 task 참조 성공률 |
| 6 | 실패 복구 | 장애 시 graceful degradation | fallback 모드 진입 성공률 |
